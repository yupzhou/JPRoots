# 功能介绍

1. **多语言支持**  
   2 种输入语言 + 8 种输出语言。
2. **动态推导**  
   将历史上的音变用规则表达，链式依次替换，边输入，边输出。
3. **演变历程时间轴**  
   横向滚动轨道、动态生成阶段、水平滚动条交互、音变规则描述面板，可视化的语言演变。
4. **输入输出清洗**  
   对一些异常的输入，或推导过程中产生的异常形式进行清洗。
